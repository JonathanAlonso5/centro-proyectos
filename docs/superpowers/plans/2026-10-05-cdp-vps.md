# Migración CdP a VPS

Autorizada por Jonathan: web + API/MCP + datos en cdp.friday-imperio.com, como ORQUESTA; mantener integraciones y datos.

Diseño: adaptar los handlers existentes a Node y SQLite, sin reescribir lógica; servidor solo localhost, túnel independiente y servicio systemd. Dominio anterior queda como proxy de compatibilidad hacia la única base nueva. Conservar secreto/sesiones y OAuth; Google accede por popup del origen ya autorizado. Inicialmente Node usa D1 remoto. Cuando tráfico antiguo y nuevo llega a Node, bloquear admisión brevemente (solicitudes esperan), terminar operaciones en curso, bloquear escrituras en D1 mediante triggers reversibles (incluye versiones antiguas), copiar tablas de D1 incluyendo meta, comprobar integridad, cambiar a SQLite y liberar solicitudes; jamás dos bases aceptando escrituras. Copias privadas y rollback: antes de activar, retirar bloqueo D1 y volver al origen; después de activar, mantener SQLite y restaurar una release de aplicación comprobada, nunca el snapshot D1 antiguo.
